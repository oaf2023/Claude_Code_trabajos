**PLANTILLA DE CABECERA DE SCRIPTS**

CADA script generado o modificado debe incluir estrictamente la siguiente cabecera en la sintaxis de comentarios correspondiente al lenguaje:

/* ============================================================================

* Archivo         : [Nombre del archivo con extensión]
* Descripción  : [Breve descripción de la funcionalidad del script]
* Autor             :[Nombre del usuario]
* Fecha             : [YYYY-MM-DD]
* Versión          : [x.x.x]
* Lenguaje       : [Ej: Python 3.10 / TypeScript 5.0]
* Uso                : [Instrucciones breves de cómo ejecutarlo]
* ============================================================================ */

CADA función generada o modificada debe incluir estrictamente la siguiente cabecera en la sintaxis de comentarios correspondiente al lenguaje:

/* ============================================================================

* Función         : [Nombre de la función]
* Descripción  : [Breve descripción de la funcionalidad de la función]
* Fecha            : [YYYY-MM-DD]
* Versión          : [x.x.x]
* Lenguaje        : [Ej: Python 3.10 / TypeScript 5.0]
* Conexiones    :  [Si tiene conexión con otra función, script o API]
* Ingesta            :  [Datos y tipos que se deben pasar a la función]
* Devolución     :  [Retorno de la función]
* Uso                  : [Instrucciones breves de cómo ejecutarlo]
* ============================================================================ */
