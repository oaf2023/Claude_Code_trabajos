Esta documentación permite responder, entre otras, las siguientes preguntas
usando el documento y sus anexos:

- ¿Qué hace la aplicación? → capítulos 2 y 4.
- ¿Cómo funciona? → capítulos 3, 4 y anexos A–D.
- ¿Cómo se instala y ejecuta? → capítulo 7.
- ¿Cómo se utiliza? → capítulo 8.
- ¿Cómo está organizada y qué hace cada archivo? → capítulo 5, anexos A–G.
- ¿Qué hace cada función/clase/variable importante? → anexos A–G (análisis
  línea por línea) e índices del capítulo 5.
- ¿Qué API y base de datos utiliza? → capítulos 5 y 6; anexos C y D.
- ¿Cómo fluye la información? → capítulo 3 (6.7) y trazabilidad 6.8.
- ¿Dónde está implementada cada funcionalidad? → anexos (por archivo).
- ¿Qué archivo hay que modificar para un cambio? → capítulo 7 (mantenimiento).
- ¿Qué riesgos técnicos existen? → capítulo 6.
- ¿Qué dependencias utiliza? → capítulo 5 (7.7).
- ¿Qué partes parecen obsoletas? → capítulo 6 (8.5) y anexos.
