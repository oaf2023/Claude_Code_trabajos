# Politica de Privacidad Base

## 1. Introduccion

SafeAlert es una aplicacion orientada a asistencia en situaciones de emergencia. Esta politica describe que datos puede tratar la aplicacion y con que finalidad.

## 2. Datos que pueden tratarse

- Ubicacion del usuario al disparar una alerta.
- Contactos seleccionados como contactos de confianza.
- Audio opcional si el usuario habilita el microfono para adjuntar evidencia a una alerta.
- Datos tecnicos minimos necesarios para operar servicios de autenticacion, almacenamiento y mensajeria.

## 3. Finalidad del tratamiento

- Permitir el envio de alertas a contactos definidos por el usuario.
- Compartir informacion de ubicacion necesaria para una emergencia.
- Guardar evidencia asociada a una alerta cuando el usuario lo permita.
- Operar la infraestructura tecnica de la aplicacion.

## 4. Servicios de terceros

SafeAlert puede utilizar servicios de terceros para operar la aplicacion, incluyendo Firebase y servicios de mensajeria como Twilio.

## 5. Conservacion y seguridad

Los datos deben protegerse con medidas razonables de seguridad y limitarse al minimo necesario para el funcionamiento del servicio.

## 6. Control del usuario

El usuario puede decidir si concede o no permisos sensibles como ubicacion, contactos, notificaciones y microfono. Sin esos permisos, algunas funciones pueden no estar disponibles.

## 7. Revision legal

Este texto es una base operativa. Debe revisarse juridicamente antes de publicarse como politica oficial.
